mongocxx::v1::string_options Class Reference

#include <mongocxx/v1/string_options.hpp>

Description

Options related to string queries for Queryable Encryption.

Supported fields include:

  • case_sensitive ("caseSensitive")
  • diacritic_sensitive ("diacriticSensitive")
  • prefix_opts ("prefix")
  • suffix_opts ("suffix")
  • substring_opts ("substring")
See also
  • Client Side Encryption (MongoDB Specifications)
  • Encrypted Fields and Enabled Queries (MongoDB Manual)
